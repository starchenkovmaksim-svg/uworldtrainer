UWorld Trainer — блоки 1–21

Распакуйте архив целиком и откройте index.html в браузере. Интернет не нужен.
Папки assets и файл data.js должны остаться рядом с index.html.
Без входа прогресс сохраняется в браузере на этом устройстве.
Для общего прогресса настройте Supabase и GitHub Pages по SETUP.md.

В блоке 2 исходный PDF содержит только вопросы 1–29, поэтому результат считается из 29.
В блоках 2–21 часть ключей восстановлена из объяснений, остальные вопросы проверяются вручную после чтения объяснения. Подсчёт результата учитывает подтверждённую самопроверку.
В исходном block 19.pdf после сорокового вопроса есть отдельный скриншот вопроса 1 без объяснения; он сохранён в assets/block19/extra_p133.webp и не включён в балл.

Задачи по темам
Откройте topics.html или кнопку «Задачи по темам» на главной странице.
13 тем и 2849 заданий из предоставленных тематических PDF. Названия тем соответствуют названиям документов.
Прогресс по темам хранится отдельно от блоков 1–21 и синхронизируется через тот же аккаунт.
Для связанных заданий доступно условие предыдущего клинического случая.
Некоторые PDF ссылаются на отсутствующие внешние изображения и медиафайлы; такие задания отмечены уведомлением.
